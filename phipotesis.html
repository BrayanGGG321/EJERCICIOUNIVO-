Fórmulas esenciales para una media poblacional

Estadístico Z (Distribución Normal Estándar)

Se utiliza cuando se conoce la desviación estándar poblacional (σ).

Z = x − μ0 σ / √n

Estadístico t (Distribución T de Student)

Se utiliza cuando se desconoce σ y se usa la desviación muestral (s), con gl = n − 1.

t = x − μ0 s / √n
